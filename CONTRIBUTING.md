# Contributing to SmartRemit App

Thanks for your interest!

## How to contribute

1. Fork the repo
2. Create a new branch
3. Make your changes
4. Submit a pull request

## Areas where help is needed

- Improve frontend UI
- Fix API error handling
- Optimize ML integration
- Add charts and visualization improvements

## Rules

- Do not push directly to main
- Keep code clean and readable
- Explain your changes in PR
